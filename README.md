# 🛺 DropAt Rides

> A multi-service campus mobility app built for students — designed to simplify getting around campus.

---

## 📌 Overview

DropAt Rides is a campus mobility platform developed under a **Project Based Learning (PBL)** initiative at Manipal University Jaipur. It aims to streamline student transportation on campus by offering a multi-service ride experience with a clean, intuitive interface and real-time backend support.

🏆 **Winner – Project Expo 2025** | Selected from the top 10–15 projects out of 100+ submissions.

---

## ✨ Features

- 🔐 **Firebase Authentication** — Secure sign-up and login for students
- 📡 **Real-time Data Handling** — Live updates powered by Firebase Realtime Database
- 🎨 **Intuitive UI/UX** — Designed in Figma with a student-first experience in mind
- 🚀 **Scalable Backend** — Ongoing development focused on reliability and performance at scale

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| UI/UX Design | Figma |
| Authentication | Firebase Auth |
| Database | Firebase Realtime Database |
| Backend | Node.js (in progress) |

---

## 🚧 Project Status

DropAt Rides is actively progressing toward **real-world deployment**. Backend development is ongoing with a focus on improving scalability and service reliability.
